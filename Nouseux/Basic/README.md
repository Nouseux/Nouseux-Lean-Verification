# Basic Proofs — Simplified Structure

This folder contains simplified Lean 4 proofs created as a first iteration
of the Nouseux formal verification framework.

**Created:** September 19, 2026  
**Status:** Educational baseline

These proofs establish the basic structure but use simplified bounds.
For the complete formal proofs matching Version 1.04ter, see `../Formal/`.

## Files

- `NAI_Bounds.lean` — Simplified NAI bounds (1.5 ≤ NAI ≤ 2.5)
- `Threshold.lean` — Basic threshold regime proof
- `Recursion.lean` — Basic recursion stability proof
