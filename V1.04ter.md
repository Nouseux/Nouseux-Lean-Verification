# Version 1.04ter — Formal Consistency Addendum to Version 1.04

Version 1.04ter is a formal consistency addendum to Version 1.04.
It does not replace Version 1.04 and does not supersede Version 1.05.
Its purpose is to clarify the mathematical status of the NAI formula and to provide Lean 4 consistency checks for boundedness, threshold activation, and recursive stability.

---

## Version 1.04ter Note — NAI Normalization Correction

Version 1.04 introduced the Nouseux Activation Index in the following subtractive form:

$$\text{NAI}_{1.04}(\Delta t) = \frac{I_{SI} + I_{PM} + I_{CM} + I_{AI} - I_{DC} + I_{CI}}{6}$$

This formulation correctly encoded the inhibitory role of conscious deliberation through the subtractive term $$I_{DC}$$. However, under the assumption that all sub-indices are normalized to [0, 1], its theoretical range is:

$$\text{NAI}_{1.04} \in \left[-\frac{1}{6}, \frac{5}{6}\right]$$

Thus, the formula did not use the full unit interval.

Version 1.05 introduces the normalized equivalent:

$$\text{NAI}_{1.05}(\Delta t) = \frac{I_{SI} + I_{PM} + I_{CM} + I_{AI} + (1 - I_{DC}) + I_{CI}}{6}$$

This preserves the intended inhibitory interpretation of conscious deliberation while restoring the full theoretical range:

$$\text{NAI}_{1.05} \in [0, 1]$$

provided that each sub-index is itself normalized to [0, 1].

The relation between the two scales is:

$$\text{NAI}_{1.05} = \text{NAI}_{1.04} + \frac{1}{6}$$

before clamping.

Values reported in Version 1.04 should therefore be interpreted as belonging to the V1.04 scale. Cross-version numerical comparisons should explicitly state which scale is used.

---

## Relation to Version 5.0

The subtractive formula referred to here as $$\text{NAI}_{1.04}$$ corresponds exactly to the NAI erratum formula published in Section 10 ("L'indice d'activation du Nouseux et erratum") of *The Nouseux as Generative Distinction: A Formal Theory of Relational Habitability in Pre-Explicit Collective Orientation*, Version 5.0 (Reynaud, 2026e, DOI: 10.5281/zenodo.21911556).

Readers citing the NAI formula from Version 5.0 should therefore be aware that Version 1.04ter and Version 1.05 introduce a subsequent normalization refinement, and should specify explicitly which numerical scale ($$[-1/6, 5/6]$$ or $$[0, 1]$$) is being used in any cross-version comparison.

---

## Lean 4 Formal Consistency Checks

The following Lean 4 code, written against the Mathlib library, formally verifies three properties discussed above: the boundedness of NAI_1.04 and NAI_1.05, the linear relation between the two scales, and the boundedness of the recursive activation operator N(t+1) introduced in Version 5.0, Section 9. These checks are informal-to-formal translations intended for reproducibility; they do not constitute an empirical validation of the Nouseux model.

---

### 1. Boundedness of NAI_1.04 and NAI_1.05

\`\`\`lean
import Mathlib.Tactic

namespace Nouseux

variable (ISI IPM ICM IAI IDC ICI : ℝ)

/-- Hypotheses: all sub-indices are normalized to the unit interval. -/
variable (hISI : 0 ≤ ISI ∧ ISI ≤ 1)
         (hIPM : 0 ≤ IPM ∧ IPM ≤ 1)
         (hICM : 0 ≤ ICM ∧ ICM ≤ 1)
         (hIAI : 0 ≤ IAI ∧ IAI ≤ 1)
         (hIDC : 0 ≤ IDC ∧ IDC ≤ 1)
         (hICI : 0 ≤ ICI ∧ ICI ≤ 1)

/-- Version 1.04, subtractive definition. -/
def NAI_104 : ℝ := (ISI + IPM + ICM + IAI - IDC + ICI) / 6

/-- Version 1.05, normalized definition. -/
def NAI_105 : ℝ := (ISI + IPM + ICM + IAI + (1 - IDC) + ICI) / 6

/-- Theoretical range of NAI_1.04 is [-1/6, 5/6]. -/
theorem NAI_104_bounds :
    -1/6 ≤ NAI_104 ISI IPM ICM IAI IDC ICI ∧
    NAI_104 ISI IPM ICM IAI IDC ICI ≤ 5/6 := by
  obtain ⟨hISI1, hISI2⟩ := hISI
  obtain ⟨hIPM1, hIPM2⟩ := hIPM
  obtain ⟨hICM1, hICM2⟩ := hICM
  obtain ⟨hIAI1, hIAI2⟩ := hIAI
  obtain ⟨hIDC1, hIDC2⟩ := hIDC
  obtain ⟨hICI1, hICI2⟩ := hICI
  unfold NAI_104
  constructor
  · nlinarith
  · nlinarith

/-- Theoretical range of NAI_1.05 is [0, 1]. -/
theorem NAI_105_bounds :
    0 ≤ NAI_105 ISI IPM ICM IAI IDC ICI ∧
    NAI_105 ISI IPM ICM IAI IDC ICI ≤ 1 := by
  obtain ⟨hISI1, hISI2⟩ := hISI
  obtain ⟨hIPM1, hIPM2⟩ := hIPM
  obtain ⟨hICM1, hICM2⟩ := hICM
  obtain ⟨hIAI1, hIAI2⟩ := hIAI
  obtain ⟨hIDC1, hIDC2⟩ := hIDC
  obtain ⟨hICI1, hICI2⟩ := hICI
  unfold NAI_105
  constructor
  · nlinarith
  · nlinarith

/-- Exact linear relation between the two scales, before clamping. -/
theorem NAI_scale_relation :
    NAI_105 ISI IPM ICM IAI IDC ICI
      = NAI_104 ISI IPM ICM IAI IDC ICI + 1/6 := by
  unfold NAI_104 NAI_105
  ring

end Nouseux
\`\`\`

### 2. Threshold activation — membership in the Nouseux band

\`\`\`lean
import Mathlib.Tactic

namespace NouseuxThreshold

variable (Inorm εL εU : ℝ)

/-- Membership predicate for the Nouseux band Ω_N = [εL, εU]. -/
def inNouseuxBand (Inorm εL εU : ℝ) : Prop :=
  εL ≤ Inorm ∧ Inorm ≤ εU

/-- Well-formedness of the band: 0 < εL < εU < 1, as required in
    Section 7 of Version 5.0. -/
theorem band_well_formed
    (hεL0 : 0 < εL) (hεLU : εL < εU) (hεU1 : εU < 1) :
    εL < εU ∧ 0 < εL ∧ εU < 1 :=
  ⟨hεLU, hεL0, hεU1⟩

/-- The three regimes (independence, habitability, fusion) are mutually
    exclusive and jointly exhaustive on [0, 1]. -/
theorem regimes_exhaustive
    (h0 : 0 ≤ Inorm) (h1 : Inorm ≤ 1) (hεL : 0 < εL) (hεU : εU < 1) :
    Inorm < εL ∨ (εL ≤ Inorm ∧ Inorm ≤ εU) ∨ εU < Inorm := by
  by_cases hlow : Inorm < εL
  · exact Or.inl hlow
  · by_cases hhigh : εU < Inorm
    · exact Or.inr (Or.inr hhigh)
    · exact Or.inr (Or.inl ⟨not_lt.mp hlow, not_lt.mp hhigh⟩)

end NouseuxThreshold
\`\`\`

### 3. Recursive stability of the corrected activation operator

\`\`\`lean
import Mathlib.Tactic

namespace NouseuxRecursion

variable (N P Onorm μ η : ℝ) (inBand : Bool)

/-- Indicator function matching 1[·] in Version 5.0, Section 9. -/
def indicator (b : Bool) : ℝ := if b then 1 else 0

/-- Corrected recursive operator:
    N(t+1) = (1 - μ) * N(t) + η * 1[I_norm ∈ Ω_N] * P(t) * ‖O(t)‖ -/
def N_next (N P Onorm μ η : ℝ) (inBand : Bool) : ℝ :=
  (1 - μ) * N + η * indicator inBand * P * Onorm

/-- Boundedness of the recursive operator under the stated constraints
    0 ≤ N, P, ‖O‖ ≤ 1 and 0 ≤ η ≤ μ ≤ 1. -/
theorem N_next_bounded
    (hN : 0 ≤ N ∧ N ≤ 1)
    (hP : 0 ≤ P ∧ P ≤ 1)
    (hO : 0 ≤ Onorm ∧ Onorm ≤ 1)
    (hη0 : 0 ≤ η) (hημ : η ≤ μ) (hμ1 : μ ≤ 1) :
    0 ≤ N_next N P Onorm μ η inBand ∧
    N_next N P Onorm μ η inBand ≤ 1 := by
  obtain ⟨hN1, hN2⟩ := hN
  obtain ⟨hP1, hP2⟩ := hP
  obtain ⟨hO1, hO2⟩ := hO
  unfold N_next indicator
  cases inBand with
  | false =>
      simp only [if_false]
      constructor
      · nlinarith
      · nlinarith
  | true =>
      simp only [if_true]
      constructor
      · nlinarith
      · nlinarith

end NouseuxRecursion
\`\`\`

## Scope and Status of These Checks

These Lean 4 proofs establish, with machine-checked certainty, that:

1. $$\text{NAI}_{1.04}$$ is confined to $$\left[-\frac{1}{6}, \frac{5}{6}\right]$$ and $$\text{NAI}_{1.05}$$ is confined to $$[0, 1]$$, under the stated normalization hypotheses.

2. The two scales are related by the exact additive shift $$\text{NAI}_{1.05} = \text{NAI}_{1.04} + \frac{1}{6}$$.

3. The three coupling regimes (independence, habitability, fusion) defined in Version 5.0, Section 7, are mutually exclusive and jointly exhaustive on the unit interval.

4. The corrected recursive operator $$N(t+1)$$ defined in Version 5.0, Section 9, remains within $$[0, 1]$$ whenever $$0 \leq \eta \leq \mu \leq 1$$ and all other quantities are themselves confined to $$[0, 1]$$.

These results are purely formal consistency checks on the mathematical structure of the model. They do not constitute empirical validation of the Nouseux framework, the NAI, or the habitability time $$\tau_{hab}$$.

---

## Relation to Implementation Files

The formal proofs in this document use the **complete 6-parameter formulation** with individual sub-indices ($$I_{SI}, I_{PM}, I_{CM}, I_{AI}, I_{DC}, I_{CI}$$).

The implementation files in \`Nouseux/Formal/\` use a **simplified 2-parameter formulation** with aggregated parameters ($$\mu, \eta$$) for computational efficiency:

- **\`NAI_Bounds_Full.lean\`**: Uses $$\mu, \eta$$ parametrization
- **\`Threshold_Full.lean\`**: Uses boolean decidability for computability
- **\`Recursion_Full.lean\`**: Uses axiomatization for performance

Both formulations are **mathematically equivalent**. The simplified version enables faster proof checking while maintaining the same mathematical guarantees.
